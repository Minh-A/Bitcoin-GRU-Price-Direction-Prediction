# Data

The original raw and merged datasets are not committed. They were collected from market and macro sources including Upbit, Binance, CryptoQuant, Naver Finance, exchange-rate data, CPI data, and gold prices.

This repository includes `sample_real_final_data.csv`, a small sample of the processed feature table for code inspection and smoke tests. For full experiments, place the complete processed table at:

```text
data/real_final_data.csv
```

The modeling scripts accept a custom path with `--data`.
